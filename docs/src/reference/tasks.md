# Task History

Beads is authoritative for executable feature and task state. Use `bd ready`, `bd show <id> --json`, and the lifecycle
skills described in [Feature Lifecycle](../development/feature-lifecycle.md) instead of Markdown task lists.

Completed capability and audit evidence is available in [Implemented Features](../features/index.md). Active and future
feature intent is summarized in [Planned Features](../planned-features.md).

Legacy Markdown task files were preserved as migration evidence outside the reader-facing documentation tree. They are
historical inputs only and must not be used to select or authorize work.
